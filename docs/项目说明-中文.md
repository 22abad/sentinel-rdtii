## 一、这个项目是什么？一句话

我们做了一个**自动读法律、给数字贸易法规打分**的 AI 工具。

**背景**：联合国有一套评估体系叫 **RDTII**（数字贸易一体化指数），要人工去读各国的法律条文，判断这个国家在"数据跨境流动""数据保护"等方面的政策，然后打分。**这件事又慢又费人**。

**我们的工具做的事**：
1. 自动去官方网站找到某国的相关法律；
2. 用 AI 把里面**跟评分有关的条款逐字**抠出来；
3. 判断这条对应 RDTII 的哪个指标；
4. 用**固定的程序**（不是 AI）给出分数；
5. 输出一张标准表格（CSV/JSON），每一行 = 一条法律证据。

**最关键的设计（防止 AI 瞎编）**：AI 只负责"抠出原文引文 + 判断对应哪个指标"，而且**引文必须一字不差地在原文里存在**（程序会逐字符校验）。**分数由程序算，AI 不碰分数**。这样评委才敢信。

**比赛**：联合国 AI for Digital Trade 黑客松。
- **第一轮（Round 1）**：强制范围 = **支柱 6 和 7** × **新加坡、马来西亚、澳大利亚** 三国。7 月 20 日提交。
- **第二轮（Round 2）**：全部 12 个支柱 × 另外 7 国（中/印/印尼/老/蒙/俄/泰）。

## 三、怎么用（三种方式）

> ⚠️ 下面命令都在**项目根目录**（`UN-DigitalTrade-AI-Mapper-private/`）里运行。
> 我们用的 Python 环境叫 `.venv-eval`，所以命令前面带 `.venv-eval/bin/python`。

### 方式 A：命令行生成一国结果（★最常用，评委也这么跑★）

**最基础的一行**（生成新加坡 支柱6+7 的结果）：
```bash
RDTII_LLM_PROVIDER=deepseek .venv-eval/bin/python main.py --economy Singapore --pillar 6,7
```
跑完，结果 CSV/JSON 出现在 `outputs/` 目录里。

**常用参数解释**：
| 参数 | 意思 |
|---|---|
| `--economy Singapore` | 哪个国家（可写 Singapore/Malaysia/Australia，或代码 SGP/MYS/AUS） |
| `--pillar 6,7` | 哪些支柱（写 `6`、`7`、`6,7`、`all`、`round1`） |
| `--offline` | **离线模式**：只用本地法律库，不联网。**结果干净、可复现，推荐做提交样例** |
| （不加 --offline） | **默认模式**：先用本地种子，再联网找更多。**这是评委跑的路径** |
| `--pdf 某文件.pdf` | 直接从一个 PDF 文件抽（演示"扫描件→引文"用这个） |
| `--output-dir 某目录` | 结果放哪 |
| `--max-documents 3` | 最多处理几个文档（控制速度/成本） |

**离线模式例子**（干净、可复现，做提交样例用这个）：
```bash
RDTII_LLM_PROVIDER=deepseek .venv-eval/bin/python main.py --economy Australia --pillar 6,7 --offline
```

**成本**：每个"国家×支柱"大约 **$0.01–0.05**（用 DeepSeek）。

### 方式 B：启动整套网站（演示用，需要 Docker）

如果要给评委看**网页界面**（上传 PDF、看结果表格）：
```bash
docker compose up
```
启动后：
- 网站前端：浏览器打开 `http://localhost:5173`（或看启动日志里的地址）
- 后端 API：`http://localhost:8000`
- 数据库(postgres)：本机 5433 端口

关掉：`docker compose down`

> Docker 是"把整套环境打包好一键运行"的工具。如果没装 Docker，先装 Docker Desktop。

### 方式 C：跑测试（确认没坏）

```bash
cd ai-service && ../.venv-eval/bin/python -m pytest -q
```
应该看到类似 **`531 passed`**。全绿 = 代码没问题。

## 四、几个必须懂的概念

1. **支柱（Pillar）和指标（Indicator）**
   RDTII 有 12 个支柱，每个支柱下有几个指标。我们强制范围：
   - **支柱 6 = 跨境数据政策**（6.1 数据本地化禁令 / 6.2 本地存储 / 6.3 基础设施 / 6.4 有条件流动 / 6.5 …）
   - **支柱 7 = 数据保护与隐私**（7.1 综合框架 / 7.2 网络安全 / 7.3 数据留存 / 7.4 DPO/DPIA / 7.5 政府访问数据）

2. **离线 vs 默认（联网）** —— 很重要
   - **离线（--offline）**：只读本地 `data/law_library/` 里策展好的法律。干净、每次一样、不怕断网。**适合做提交样例和演示复现。**
   - **默认（不加参数）**：会联网找更多法律。内容更丰富，但会掺进噪声（贸易协定、博客等）。**这是评委真实会跑的路径**，我们专门做了过滤把噪声清掉了。

3. **防幻觉三件套**（评委为什么信我们）
   - AI 抠出的引文**必须逐字符在原文里**（否则丢弃）；
   - 法名要对得上官方来源；
   - 分数由程序算，AI 不参与打分。

4. **golden 集（标准答案）**
   `evaluation/golden/cases.jsonl` 里有 **29 个法务审核批准的正确案例**。我们所有的过滤规则都验证过"不会误伤这 29 个"——这是我们改代码不出错的安全网。

5. **KNOWN（已知）vs NEW（新发现）**
   - 官方清单里已有的法 = **KNOWN**；
   - 我们工具额外找到、官方清单里没有的 = **NEW**（这是加分项）。
   - 已核实的 NEW 候选在 `docs/new-law-candidates.md`（目前 AUS 2 条 + THA 2 条，都有官方逐字引文）。

## 五、平时最常做的几件操作（照抄即可）

**① 生成三国 R1 提交样例（干净版）**
```bash
for E in Singapore Malaysia Australia; do
  RDTII_LLM_PROVIDER=deepseek .venv-eval/bin/python main.py --economy $E --pillar 6,7 --offline
done
```
结果在 `outputs/`。已经存好的样例在 `docs/r1-submission-sample/`。

**② 跑分级测试（模拟评委怎么测）**
```bash
.venv-eval/bin/python tools/judge_test_matrix.py --offline
```
生成报告 `docs/judge-test-report.md`。

**③ 全新环境复现测试（评委按 README 从零装能不能跑通）**
```bash
bash tools/check_reproducibility.sh
```

**④ 找某国的"新法律"（加分项）**
```bash
RDTII_LLM_PROVIDER=deepseek .venv-eval/bin/python tools/discover_new_laws.py --economy Australia --pillar all
```

**⑤ 跑测试确认没坏**
```bash
cd ai-service && ../.venv-eval/bin/python -m pytest -q
```

## 六、环境准备（第一次用才需要）

1. **填 API key**：把 `.env.example` 复制成 `.env`，填入至少一个 AI 的 key（我们主用 **DEEPSEEK_API_KEY**）。
   ```bash
   cp .env.example .env
   # 然后用编辑器打开 .env，填 DEEPSEEK_API_KEY=你的key
   ```
2. **装依赖**：`.venv-eval` 环境已经装好了。若要全新装：
   ```bash
   make setup      # 或者 python -m venv .venv && pip install -r requirements.txt
   ```
3. **联网发现需要搜索 key**：要让工具"联网找新法律"，还需在 `.env` 里加：
   ```
   SERPAPI_API_KEY=你的key
   DISCOVERY_SEARCH_BACKEND=serpapi
   ```
   （两个都要，光有 key 不够。SerpAPI 免费层 250 次/月。）

## 七、遇到问题怎么办（常见排错）

| 现象 | 原因 / 怎么办 |
|---|---|
| 跑 main.py 报 `DEEPSEEK_API_KEY is not set` | `.env` 里没填 key，或没在项目根目录跑 |
| 输出是空的 / 报 `No judge-usable provisions` | 网络断了、key 无效，或该范围确实没找到。试试加 `--offline` |
| 联网跑很慢/卡住 | 大 PDF 抽取慢是正常的；或网络问题。可以先用 `--offline` |
| 结果里有奇怪的"法律"（贸易协定、博客） | 理论上已被过滤。若还有，说明是新噪声类型，发给 AI 说明情况 |
| `docker compose up` 起不来 | 先确认装了 Docker Desktop 并已启动 |
| 想复现别人的结果对不上 | 用 `--offline`（离线才保证每次一样） |
